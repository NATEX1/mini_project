# ระบบลงทะเบียนผู้ป่วยและจัดการคิวโรงพยาบาล (Hospital Patient Registration & Queue Management System)

ระบบเว็บแอปพลิเคชันพัฒนาด้วย **PHP (PDO)** รองรับฐานข้อมูล **MySQL / MariaDB** และจัดการผ่าน **phpMyAdmin** มีฟังก์ชันครบวงจรตั้งแต่การลงทะเบียนผู้ป่วย การออกบัตรคิว การเรียกคิวด้วยเสียงภาษาไทย (Thai Text-To-Speech) และหน้าจอแสดงผลคิวสำหรับผู้ป่วย (TV Queue Display)

---

## 🗄️ การติดตั้งฐานข้อมูลผ่าน phpMyAdmin

1. เปิดเบราว์เซอร์ไปที่ **phpMyAdmin** ของคุณ (เช่น `http://localhost/phpmyadmin` หรือ `http://localhost:8080`)
2. ไปที่แท็บ **Import (นำเข้า)**
3. เลือกไฟล์ `schema.sql` ในโฟลเดอร์โปรเจกต์นี้
4. กดปุ่ม **Import / Go** ที่ด้านล่าง
5. ระบบจะสร้างฐานข้อมูลชื่อ `hospital_queue_db` พร้อมตารางทั้ง 5 ตารางและข้อมูลทดสอบให้อัตโนมัติ:
   - `patients` (ตารางผู้ป่วย)
   - `departments` (ตารางแผนกตรวจ)
   - `staff` (ตารางเจ้าหน้าที่)
   - `visits` (ตารางการมาตรวจ)
   - `queues` (ตารางคิว)

> 💡 **การตั้งค่ารหัสผ่านฐานข้อมูล:**  
> หากใช้ XAMPP ปกติรหัสผ่าน `root` จะว่างเปล่า ระบบตั้งค่าเริ่มต้นให้แล้วที่ `config/database.php`

## 🐳 หรือรันผ่าน Docker (แนะนำ สะดวกที่สุด)

หากต้องการรันด้วย Docker ทั้งเว็บ, ฐานข้อมูล และ phpMyAdmin สามารถเปิด Terminal ในโฟลเดอร์นี้แล้วพิมพ์:

```bash
docker compose up -d
```

- **หน้าเว็บแอปพลิเคชัน:** [http://localhost:8000](http://localhost:8000)
- **phpMyAdmin:** [http://localhost:8080](http://localhost:8080)  
  *(User: `root` / Password: `rootpassword` - ไฟล์ `schema.sql` จะถูกนำเข้าให้อัตโนมัติ)*

## 🌟 จุดเด่นและฟังก์ชันการใช้งาน

1. **ระบบลงทะเบียนผู้ป่วย (Patient Registration):**
   - รันเลขประจำตัวผู้ป่วย (HN) ให้อัตโนมัติ เช่น `HN-260005`
   - ตรวจสอบความถูกต้องของเลขประจำตัวประชาชน 13 หลัก
   - One-Stop Service: สามารถติ๊กถูกเพื่อ "ออกบัตรคิวทันที" หลังลงทะเบียนได้เลยในขั้นตอนเดียว
2. **ระบบออกบัตรคิว (Queue Ticket Issuance):**
   - รันเลขคิวตามรหัสแผนก เช่น อายุรกรรม `MED-001`, ทันตกรรม `DEN-001`
   - หน้าพิมพ์บัตรคิว (Thermal Slip) จัดรูปแบบสวยงาม สั่งพิมพ์ลงเครื่องพิมพ์ความร้อน 80mm/58mm ได้ทันที
3. **โต๊ะเรียกคิวสำหรับแพทย์/พยาบาล (Queue Calling Desk):**
   - กรองตามแผนกตรวจได้สะดวกรวดเร็ว
   - กดปุ่ม **"เรียกคิว"** เพื่อสั่งสังเคราะห์เสียงพูดภาษาไทยอัตโนมัติ *"ขอเชิญหมายเลข ... ที่ห้องตรวจ ... ค่ะ"*
   - ปุ่มเปลี่ยนสถานะ: เข้าตรวจ (Serving), เสร็จสิ้น (Completed), ยกเลิก (Cancelled)
4. **หน้าจอทีวีแสดงคิวสำหรับผู้ป่วย (TV Queue Display Board):**
   - ออกแบบธีมมืด สวยงาม มองเห็นชัดเจนจากระยะไกล
   - แบ่งฝั่ง "กำลังรับบริการ" และ "รอรับบริการ"
   - เชื่อมต่อเสียงขานอัตโนมัติแบบ Real-time และมีปุ่มเต็มจอ (Fullscreen)
5. **ความปลอดภัย:**
   - ใช้ **PDO Prepared Statements** ป้องกัน SQL Injection 100%
   - รหัสผ่านเข้ารหัสด้วยมาตรฐาน **bcrypt** (`password_hash`)
